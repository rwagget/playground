# Playground

Hub of small web experiments, hosted on GitHub Pages (rwagget/playground).

- Each experiment lives in `experiments/<slug>/index.html`.
- New experiments start as a blank page (just the HTML skeleton, no content) and have no links back to the hub or home page.
- Every new experiment must also get an entry in `experiments.json` — the hub (`index.html`) renders cards from it.
- Plain HTML/CSS/JS, no build step. Self-contained per experiment unless asked otherwise.
- This is separate from the Inspo App project; don't touch that folder.
